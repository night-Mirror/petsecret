## 环境动态（最新要求）
视频场景需要自然动起来，不能只让人物动、背景完全静止。按场景加入风吹树枝叶片、流云与薄雾等连续动态；人物发梢、袖口、衣摆与树叶风向一致。动静有层次，环境不抢对白、不遮挡主体。固定镜头不等于静止环境；亭子、地面、山体等刚性结构保持稳定，不用整张画面平移或抖动冒充环境动画。
当前亭子第一镜：微风吹松枝和针叶，云海缓慢横移、山间薄雾轻微翻涌，人物发梢与衣摆轻摆。保持固定远景、人物中央及6秒整数请求。此条替代旧提示词中“背景静止”的要求。
